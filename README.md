# SoundCloud Desktop

Лёгкое десктопное приложение для SoundCloud на Windows (x64) на базе Microsoft Edge WebView2 и .NET Framework 4.x.

## Возможности

- Тёмный и настраиваемый интерфейс окна и компактная верхняя панель управления (можно скрывать).
- **Выбор темы оформления** — переключение темы через кнопку `Theme` на панели инструментов, подменю `Theme` в настройках (`⚙`) или в контекстном меню системного трея (выбранная тема сохраняется между запусками и применяется к окну, заголовку, меню, мини-плееру и окнам авторизации):
  - **Original Web (Dark Shell)** — тёмная оболочка приложения с оригинальным веб-интерфейсом SoundCloud (по умолчанию);
  - **Dark Obsidian** — тёмно-графитовая тема для интерфейса и страниц SoundCloud;
  - **Midnight OLED** — контрастная чисто чёрная тема;
  - **Light Classic** — светлая тема оформления;
  - **Synthwave Purple** — тёмно-фиолетовая тема с неоново-фиолетовым акцентом;
  - **Deep Ocean** — глубокая тёмно-синяя тема с бирюзовым акцентом.
- **Мини-плеер** — компактное окно поверх остальных окон только с элементами управления плеером.
- **Системный трей** — сворачивание в трей вместо закрытия, управление воспроизведением (`Play/Pause`, `Next`, `Previous`) и быстрое переключение режима «Поверх всех окон».
- **Единственный экземпляр** — повторный запуск активирует открытое окно и при передаче ссылки `https://soundcloud.com/...` открывает её в текущем окне.
- **Отображение текущего трека** в заголовке окна, подсказке трея и на панели инструментов (клик по названию копирует ссылку на трек в буфер обмена).
- **Встроенная блокировка рекламы (`Block Ads & Upsells`)** — включена по умолчанию: блокирует рекламные/VAST/promoted-запросы на уровне WebView2 и JS-ленты, скрывает баннеры и Go+-апселлы и автоматически пропускает аудиорекламу.
- **Сохранение состояния** — запоминает позицию и размер окна, масштаб и настройки панели.
- **Авторизация** — встроенная поддержка окон входа SoundCloud и OAuth-провайдеров (Google, Apple, Facebook и др.); внешние ссылки открываются в браузере по умолчанию.

## Горячие клавиши

| Комбинация | Действие |
|---|---|
| `Ctrl+M` | Включить / выключить мини-плеер |
| `Ctrl+H` | Показать / скрыть панель инструментов |
| `Ctrl+K` или `Ctrl+L` | Фокус на строку поиска |
| `F11` | Полноэкранный режим |
| `Ctrl++` / `Ctrl+-` / `Ctrl+0` | Увеличить / уменьшить / сбросить масштаб |
| `Alt+Left` / `Alt+Right` | Назад / вперёд по истории (также поддерживаются боковые кнопки мыши) |
| `F5` / `Ctrl+R` | Обновить страницу |

## Требования

- Windows 10 / 11 (x64)
- .NET Framework 4.x (встроенный компилятор `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`)
- [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) (обычно предустановлен в Windows 10/11)

## Сборка

Выполните в PowerShell из корневой папки проекта:

```powershell
.\build.ps1
```

Скрипт скомпилирует исходники из `src\*.cs` в `dist\SoundCloud.exe` и скопирует необходимые библиотеки WebView2 (`Microsoft.Web.WebView2.Core.dll`, `Microsoft.Web.WebView2.WinForms.dll`, `WebView2Loader.dll`).

## Установка и удаление

Установка в `%LOCALAPPDATA%\Programs\SoundCloudDesktop` с созданием ярлыков на Рабочем столе и в меню «Пуск» (`SoundCloud.lnk`):

```powershell
.\install.ps1
```

Полное удаление программы и ярлыков:

```powershell
.\install.ps1 -Uninstall
```
